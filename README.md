# htc-starters
This is my combined work from the edX courses **How to Code: Simple Data** and **How to Code: Complex Data**, both taught by Gregor Kiczales at the University of British Columbia (UBC).


I took both courses to fulfill the requirement for Systematic Programming Design (SPD) in the [Open Source Society University (OSSU)](https://cs.ossu.dev/#curriculum)'s Computer Science curriculum, which I have been pursuing for fun.
While not technically recommended, I took the paid, non-archived version of SPD, abbreviated as HTC. I did so, both because I thought getting certification would motivate me to finish the course, as well as the fact that I got
an 80% discount on both through edX's financial aid program.

I wanted to ensure that I had all of the starter files in one place. Because SPD and HTC differ in their schedules and some content, I created this git repository to easily access and update all of my solutions and log my progress.

If you would like to look at my solutions because you feel stuck in one area or another (if my code is actually that good), then go ahead. But from one student to another, **please** don't just use my code in place of your own work.
While I cannot stop you, you won't come away with the feeling that you've learned something.
